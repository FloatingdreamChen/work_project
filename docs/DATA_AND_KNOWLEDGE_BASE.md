# 数据与知识库设计

## 结构化数据

用户画像：学历、学位、专业、毕业年份、应届身份、政治面貌、户籍、基层经历、工作年限、证书。

岗位表：年份、考试类型、省份、城市、招录机关、职位名称、职位代码、招录人数、学历、专业、政治面貌、基层经历、备注、来源。

练习记录：题型、知识点、作答内容、得分、错因、Agent 批改意见、复盘状态。

## 非结构化知识库

建议导入国考公告、省考公告、报考指南、专业目录、行测大纲、申论材料、面试真题、常见政策问答。

## Milvus Collection

Collection：`gov_exam_knowledge`

字段：`id`、`doc_id`、`chunk_id`、`source_type`、`title`、`source_url`、`published_at`、`imported_at`、`content`、`embedding`。

## 检索策略

优先按考试类型、省份、年份过滤，再向量召回，使用 reranker 重排。回答时返回依据摘要、文档标题和发布日期。
