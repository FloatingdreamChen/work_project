# 安全与合规

## 用户数据

- 只采集岗位匹配和学习计划必要字段。
- 身份证号、手机号、准考证号等敏感字段默认不采集。
- 日志不得打印密码、token、完整个人画像。

## 岗位资格判断

- 不得把 AI 判断描述为官方审核结论。
- 输出应区分明确满足、明确不满足、需要人工核验。
- 每个风险判断应给出字段依据或政策依据。

## 学习与考试合规

- 不提供作弊、替考、伪造证明等建议。
- 不承诺考试结果。
- 不生成虚假经历、虚假党员身份、虚假证书说明。

## 模型输出约束

系统提示词必须包含：你不是官方招录机关；你不能替代人工资格审核；数据不足时要说明不确定性；对强时效政策要引用数据来源和日期。
