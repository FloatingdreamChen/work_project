# 项目背景

公务员考试用户通常面临岗位选择信息密集、备考周期长、资格风险难判断三个问题。本项目用 Agent + RAG 把岗位理解、资格核验、学习规划、练习复盘整合成一个本地可运行的 AI 助手。

## 目标用户

- 应届毕业生。
- 在职备考用户。
- 省考、国考、事业单位等公职考试备考用户。
- 想从岗位要求倒推学习计划的用户。

## MVP 范围

- 用户登录和个人画像。
- 岗位表导入。
- 岗位筛选与匹配报告。
- 公告、大纲、政策和题库知识库。
- 行测/申论/面试问答。
- 学习计划生成。

## 非目标

- 不做官方报名系统。
- 不替代人工资格审核。
- 不承诺录取结果。
- 不提供违规报考建议。
